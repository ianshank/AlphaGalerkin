# Migration Guide: v0.3 to v0.4

This guide covers changes, new features, and upgrade instructions when moving to **AlphaGalerkin v0.4.0**.

---

## 1. Summary of Changes
- **SBIR Presentation Flags**: `--demo` and `--export-results` added to `src.poc.cli`.
- **Domain Constants**: Constants partitioned into `src.mcts.constants`, `src.physics.constants`, `src.training.constants`.
- **Core Protocols & Registry**: New `src.core.protocols` and `src.core.registry.Registry[T]`.
- **Agent Lifecycle Hooks & Skills**: Added `src.agents.lifecycle_hooks` and `src.agents.skills` (`BenchmarkSkill`, `SelfPlaySkill`).
- **Test Suite Expansion**: Added `tests/sanity/`, `tests/security/`, `tests/benchmarks/`, `tests/regression/`, `tests/e2e/`.

---

## 2. Backward Compatibility
All previous import paths from `src.constants` remain 100% supported:
```python
# Fully backwards compatible (legacy):
from src.constants import DEFAULT_MCTS_SIMULATIONS, DEFAULT_LBB_THRESHOLD

# Preferred v0.4+ modular imports:
from src.mcts.constants import DEFAULT_MCTS_SIMULATIONS
from src.physics.constants import DEFAULT_LBB_THRESHOLD
```

---

## 3. Using New CLI Features

### SBIR Presentation Demo Mode
```bash
# Clean presentation-ready tabular output with suppressed debug logs
python -m src.poc.cli run --scenario transfer_darcy_to_poisson --demo
```

### Exporting Benchmark & Scenario Results
```bash
# Export results to JSON
python -m src.poc.cli run --scenario transfer_darcy_to_poisson --export-results results.json

# Export results to CSV
python -m src.poc.cli run --scenario transfer_darcy_to_poisson --export-results results.csv
```

## 4. Using Reusable Agent Skills & Hooks

```python
from src.agents.lifecycle_hooks import HookManager, LoggingHook, EarlyStoppingHook
from src.agents.skills import BenchmarkSkill, BenchmarkConfig

# Hook manager for custom loops
hook_manager = HookManager()
hook_manager.register(LoggingHook(name="SolverLoop"))
hook_manager.register(EarlyStoppingHook(patience=5, min_delta=1e-4))

# Benchmark skill
bench = BenchmarkSkill(BenchmarkConfig(name="mcts_eval", timing_rounds=5))
result = bench.execute(my_function, item_count=100)
print(f"Throughput: {result.throughput_items_per_s:.2f} items/sec")
```
